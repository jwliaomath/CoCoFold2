CoCoFold2: scalable latent refinement of diffusion-based protein structure predictions from limited-particle cryo-EM data.

Connect a frozen Protenix-v1 diffusion prior to particle observations. Refine a target-specific latent perturbation while keeping the network weights fixed.

THE METHOD

Refinement, in latent space.

Use a learned structural prior with informative experimental observations.

01 / CONDITION

Start from a prediction

Generate a Protenix-v1 prediction and diffusion cache. Place a compatible initial structure in the experimental coordinate frame before refinement.

02 / REFINE

Let the particles guide it

Optimize the latent perturbation against particle observations. Gaussian renderer amplitudes and widths are learned by default and can both be frozen.

03 / SCALE

Work across components

Assign one component cache to each GPU. A component can contain multiple chains; optional per-chain rigid alignment is separate from GPU assignment.

Before you begin

CoCoFold2 requires a sufficiently accurate initial prior, informative observations, and upstream particle poses and CTF estimates. It does not estimate poses or CTF parameters. Input requirements ↗
